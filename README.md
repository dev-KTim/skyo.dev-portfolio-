# skyo.dev — portfolio v2.0

Personal portfolio of Tim Kolesnikov. Hand-written in vanilla HTML, CSS and JavaScript:
no frameworks, no build step, no cookies, no tracking.

Now fully responsive (mobile included), with a 3D tilt engine, canvas starfield,
synthwave grid floor and scroll-driven animations — all respecting `prefers-reduced-motion`.

- `index.html` — the site
- `styles/main.css` — design system & all styling (see `DESIGN.md`)
- `Javascript/main.js` — all interaction & animation
- `impressum.html` / `privacy-policy.html` — German legal pages (`styles/legal.css`)
